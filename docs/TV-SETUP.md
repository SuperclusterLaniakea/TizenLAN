# 电视端设置与使用

## 前提

- 电视和运行 TizenLAN Host 的电脑 / NAS 在同一局域网。
- 电脑上已运行 host 服务（默认 `http://<电脑IP>:8099`），见 [HOST.md](HOST.md)。
- 电视已安装“局域网媒体”应用，见 [TIZEN-BUILD.md](TIZEN-BUILD.md)。

## 首次设置

1. 打开应用，首次会弹出“中转服务地址”。
2. 填电脑的局域网地址，例如 `192.168.3.88` 或 `192.168.3.88:8099`。
   - 只填 IP 时自动使用 `http://IP:8099`。
   - 也可以填完整地址，如 `http://192.168.3.88:8099`。
3. 按“测试连接”，显示“连接成功”后保存。

右上角的状态圆点表示 host 服务是否可用：绿色为在线，灰色/红色为不可用。随时按右上角按钮可以修改地址。

## 添加共享

在首页选择“添加共享”：

| 字段 | SMB | FTP |
| --- | --- | --- |
| 名称 | 自定义显示名，可留空 | 同左 |
| 服务器 | 局域网 IP 或主机名 | 同左 |
| 端口 | 默认 445 | 默认 21 |
| 共享名 | 必填，如 `MEDIA`、`video`，不是磁盘路径 | 不显示 |
| 用户名 | 共享账号；匿名/来宾可尝试留空 | 匿名可留空 |
| 密码 | 输入后仅保存在电视内存 | 同左 |
| 域 | 工作组填 `WORKGROUP`，域环境填域名 | 不显示 |
| 文件名编码 | 不显示 | 默认 UTF-8，中文乱码时切 GBK |
| 加密连接 | 不显示 | 显式 FTPS 时打开 |

保存后会立即连接。密码不写入电视存储；应用重启或电视重启后再次连接需要重新输入。

## 遥控器操作

### 首页

| 按键 | 功能 |
| --- | --- |
| 上下 | 选择入口或共享 |
| OK | 打开 / 收听 / 连接 |
| 绿色键 | 编辑选中的共享 |
| 红色键 | 删除选中的共享（会确认） |
| 返回 | 退出应用 |

首页第一项固定是“电脑声音”，按 OK 直接收听 host 电脑正在播放的声音（详见下方“电脑声音直播”）。

### 文件列表

| 按键 | 功能 |
| --- | --- |
| 上下 | 选择文件/文件夹（列表会跟随选中项滚动） |
| 左右 | 同上，逐项移动 |
| 频道 + / − | 向上 / 向下翻一页 |
| OK | 打开文件夹、播放媒体、查看图片 |
| 返回 | 上一级；在根目录时断开并回到首页 |
| 红色键 | 断开当前共享 |
| 刷新按钮 | 重新读取当前目录 |

文件夹排在文件前面，按名称排序。中文、空格、括号等文件名都可以正常显示。底部会显示当前页码和总条目数。

### 视频播放

| 按键 | 功能 |
| --- | --- |
| OK / 播放暂停键 | 暂停 / 继续 |
| ← / → | 快退 / 快进 10 秒 |
| ↑ / ↓ | 快进 / 快退 60 秒 |
| 返回 / 停止键 | 退出播放，回到文件列表 |

播放由电视 AVPlay 完成，使用的是电视硬件解码器，不走浏览器软解。Tizen 的 AVPlay 画面在网页层后面，播放时会自动把页面背景变透明以露出视频层；控制条固定在画面下方的独立区域，不会遮挡视频。播放结束会自动返回列表。

缓冲时状态显示“缓冲中…”。不能播放时显示“无法播放”和原因，约 2.6 秒后自动返回。

### 音频播放

音频使用 HTML5 播放，界面显示专辑占位图、文件名和进度。按键与视频相同（←/→ 10 秒，↑/↓ 60 秒，OK 暂停）。

### 电脑声音直播

在首页选择“电脑声音”按 OK，即可实时收听 host 电脑正在播放的声音。电视通过 HTML5 Audio 播放 MP3 流 `http://<电脑IP>:8099/audio/stream.mp3`。

| 按键 | 功能 |
| --- | --- |
| OK | 静音 / 取消静音 |
| 返回 / 停止键 | 停止收听，回到首页 |

直播没有进度条，也不支持快进快退。电脑端不需要额外设置（host 默认用 WASAPI 回环采集默认扬声器），但 host 必须运行在登录后的桌面会话；详见 [HOST.md](HOST.md) 的“电脑声音”。

### 图片查看

| 按键 | 功能 |
| --- | --- |
| ← / → | 上一张 / 下一张（循环） |
| 返回 | 关闭，回到文件列表 |

只切换当前目录内的图片文件，标题显示“文件名 (序号 / 总数)”。

## 密码与隐私

- 密码只提交给中转服务用于建立会话，电视只保存 48 位随机会话 ID。
- 密码只存在于电视应用内存和本次运行的中转服务会话中，不写 `localStorage`，不写日志。
- 关闭应用、电视重启、中转服务重启后会话失效，需要重新输入密码。
- 中转服务运行在局域网内，使用明文 HTTP；不要把它直接暴露到公网。

## 播放兼容性

| 文件 | 说明 |
| --- | --- |
| H.264 MP4 / M4V | 最稳妥，1080p 一般可直接硬解 |
| H.265 / HEVC | 取决于电视型号和固件；2015 J 系列多数型号不支持 |
| MKV / AVI / TS | 容器和编码都可能不支持，能否播放以电视为准 |
| 4K 视频 | J 系列为 1080p 面板，不建议 |
| MP3 / AAC / M4A | 通常可用 |
| FLAC / APE / WMA | 取决于电视浏览器，可能无法播放 |
| JPG / PNG | 通常可用 |

外挂字幕暂不支持（AVPlay 的网络字幕只接受本地绝对路径）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 首页右上角显示中转服务离线 | 电脑端服务未启动、电视填错 IP、防火墙拦截 8099 |
| 一直提示“正在连接…” | 共享主机不可达、端口错误、账号密码错误；查看中转服务日志 |
| SMB 提示认证失败 | 检查域（工作组 `WORKGROUP`）、共享名、账号是否允许网络登录 |
| FTP 能登录但中文乱码 | 编辑共享，把文件名编码改为 GBK / GB18030 |
| 视频黑屏、只有声音 | 若应用提示没有视频轨，说明编码不被电视支持，换 H.264 1080p 文件 |
| 视频提示无法播放 | 文件损坏、编码不支持，或中转服务读取失败（看日志） |
| 画面比例不对 | AVPlay 按视频原始比例显示；异形分辨率视频会留黑边 |
| 应用重启后要重新输入密码 | 正常行为，密码不落盘 |

## 网络建议

- 给电脑 / NAS 设置固定 DHCP 地址，避免电视里的中转服务地址失效。
- 1080p 高码率视频建议有线网络或 5GHz Wi-Fi；电视的 2.4GHz Wi-Fi 可能带宽不足。
- 中转服务只监听局域网即可，不需要端口映射或公网访问。
